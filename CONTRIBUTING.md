# Contributing / 参与

Use a branch on your Fork and run `npm run typecheck`, `npm test`, `npm run build` before proposing changes. Do not alter approved rigs, weights, model files or ActionBridge behavior without an explicit task and visual validation.

For character ideas, copy only the publicly shareable parts into a PR using `.github/PULL_REQUEST_TEMPLATE/character-idea.md`. Do not commit `character.custom.md`. Read PRIVACY.md and ASSET_LICENSE.md. Ideas are optional and will be reviewed for safety, rights, tone and compatibility; submission does not guarantee adoption.

Private custom files stay local to your deployment. The official site never imports changes from your Fork automatically. Never put real credentials into an issue, PR, screenshot or test fixture.
